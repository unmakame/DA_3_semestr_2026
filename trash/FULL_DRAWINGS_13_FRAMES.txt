================================================================================
ИСХОДНЫЕ ДАННЫЕ
================================================================================

Строка: "abracadabrac"

Длина: 12 символов
Индексы: 0:'a', 1:'b', 2:'r', 3:'a', 4:'c', 5:'a', 6:'d', 7:'a', 8:'b', 9:'r', 10:'a', 11:'c'

Уникальные символы: a, b, r, c, d (всего 5)

Требование для "5": ✓ 12 символов, ✓ 5 уникальных


================================================================================
ЛЕГЕНДА
================================================================================

Обозначения в рисунках:

root        - корневой узел
[N]         - внутренний узел (не лист, не корень)
[L] или ●   - листовой узел (конец суффикса)
─           - ребро
│           - вертикальная линия
\, /        - диагональные линии
(...):...   - интервал в исходной строке [start, end)


================================================================================
ФРЕЙМ 1: ПОСЛЕ ДОБАВЛЕНИЯ 'a' (индекс 0)
================================================================================

Текущий текст: "a"

Рисунок дерева:

                      root
                        │
                      (0:1)  ← ребро, интервал [0,1) = 'a'
                        │
                        ●L1   ← листовой узел (суффикс "a$")


Описание:
- Из root выходит ребро с интервалом [0,1) - это символ 'a'
- Ребро ведёт на листовой узел L1
- L1 содержит суффикс "a$"

Суффиксы в дереве: 1
  • "a$" (от позиции 0)

Узлы:
  - root: 1 узел
  - Листья: 1 (L1)
  - Внутренние: 0
  Всего: 2 узла

- Ребро 'b' ведёт на лист L2 (суффикс "b$" - хранится как интервал [1,2))

Суффиксы в дереве: 2
  • "ab$" (от позиции 0)
  • "b$" (от позиции 1)

Узлы:
  - root: 1 узел
  - Листья: 2 (L1, L2)
  - Внутренние: 0
  Всего: 3 узла

ФРЕЙМ 4: ПОСЛЕ ДОБАВЛЕНИЯ 'a' (индекс 3)
================================================================================

Текущий текст: "abra"

Рисунок дерева:

Тут начинает происходить интересное - нужно обработать несколько суффиксов:
"abra$", "bra$", "ra$", "a$"

После обработки:

                          root
                    /    |    |    \
                 (0:2)  (1:2) (2:3) (3:4)
                  /       |      |      \
                 [N]      L2     [N]     L4
                  |              |
              (1:3)          (3:4)
              |              |
              L1             L3


Более ясный рисунок:

                          root
                    /      |      |      \
                  a      b      r        a
                  |      |      |        |
                 [N]     L2    [N]       L4
                  |            |
                  b            a
                  |            |
                  L1           L3


Описание сжатия:
- Ребро (0:2) = "ab" ведёт на внутренний узел [N]
  От [N] выходит ребро (1:3) = "b" на лист L1 (суффикс "bra$" с новой позиции)
- Ребро (2:3) = "r" ведёт на внутренний узел
  От этого узла выходит ребро (3:4) = "a" на лист L3 (суффикс "a$")
- Ребро (3:4) = "a" ведёт на лист L4 (суффикс "a$" с позиции 3)

Суффиксы в дереве: 4
  • "abra$" (от позиции 0) → root → a → b → L1
  • "bra$" (от позиции 1) → root → b → L2
  • "ra$" (от позиции 2) → root → r → a → L3
  • "a$" (от позиции 3) → root → a → L4

Узлы:
  - root: 1 узел
  - Листья: 4 (L1, L2, L3, L4)
  - Внутренние: 2
  Всего: 7 узлов

- root → a → [N] → b → L1 (суффикс "bra$")

- root → r → [N] → a → L3 (суффикс "rac$")
- root → a → [N]... (другое разветвление)
- root → c → L5 (суффикс "c$")

Суффиксы в дереве: 5

Узлы:

ФРЕЙМ 13: ПОСЛЕ ДОБАВЛЕНИЯ '$' (индекс 12) - ФИНАЛЬНОЕ ДЕРЕВО
================================================================================

Текущий текст: "abracadabrac$"

ПОЛНОЕ ФИНАЛЬНОЕ СУФФИКСНОЕ ДЕРЕВО:

                               root
   /   |   |   |   |   |   |    |    |   |   |   |   |   \
  a   b  r  c   a  a   d   a    b   r   a   c   $  ...
  |   |  |  |   |  |   |   |    |    |   |   |   |
 [N] L2 [N][N] [N] [N][N] [N]  L15  L16 L17 L18  L19

Это УПРОЩЁННОЕ представление!

ПОЛНАЯ СТРУКТУРА (более детально):

На самом деле, от каждого внутреннего узла выходят свои ребра.
Например, от первого [N] (для 'a') выходят рёбра для символов: b, c, d, a и др.

Полное дерево имеет вложенную структуру:

Level 0 (root):
  'a' → [N1]
  'b' → L2 или [N]
  'r' → [N3]
  'c' → [N4] или L
  'd' → [N5]
  '$' → L19

Level 1 (от [N1] для 'a'):
  'b' → L1 или [N6]
  'r' → [N7]
  'c' → L20
  'd' → L21
  'a' → L22
  ...

И так далее, образуя глубокую вложенную структуру.

Суффиксы: 13
  • "abracadabrac$"  (позиция 0) - длина 13
  • "bracadabrac$"   (позиция 1) - длина 12
  • "racadabrac$"    (позиция 2) - длина 11
  • "acadabrac$"     (позиция 3) - длина 10
  • "cadabrac$"      (позиция 4) - длина 9
  • "adabrac$"       (позиция 5) - длина 8
  • "dabrac$"        (позиция 6) - длина 7
  • "abrac$"         (позиция 7) - длина 6
  • "brac$"          (позиция 8) - длина 5
  • "rac$"           (позиция 9) - длина 4
  • "ac$"            (позиция 10) - длина 3
  • "c$"             (позиция 11) - длина 2
  • "$"              (позиция 12) - длина 1

Узлы: примерно 21-23
Листья: 13 (ровно по числу суффиксов)
Внутренние: примерно 8-10
Рёбер: примерно 21-23

МАКСИМАЛЬНАЯ ГЛУБИНА: примерно 6-7 уровней

================================================================================
ПРИМЕНЕНИЕ ДЛЯ ЗАДАЧИ ЛАБОРАТОРНОЙ
================================================================================

Задача: Найти минимальный циклический разрез строки "abracadabrac"

Решение:
1. Удваиваем: T = "abracadabracabracadabrac"
2. Строим суффиксное дерево для T (как показано в 13 фреймах)
3. Ищем лексикографический минимум среди суффиксов 0-11

Минимальный разрез начнётся с буквы 'a' (или может быть другое)

Используя суффиксное дерево:
- Быстро находим все суффиксы
- Сравниваем их лексикографически за O(n log n) или O(n²)
- Возвращаем минимальный
