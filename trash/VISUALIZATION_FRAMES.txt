================================================================================
ПРИМЕНЕНИЕ ДЛЯ ЗАДАЧИ: ЛИНЕАРИЗАЦИЯ ЦИКЛИЧЕСКОЙ СТРОКИ
================================================================================

ИСХОДНАЯ ЗАДАЧА:
  Дана строка X = "abracadabrac", которая является циклическим разрезом
  неизвестной исходной циклической строки.
  
  Все возможные циклические сдвиги X:
  1. "abracadabrac"  (разрез в позиции 0)
  2. "bracadabraca"  (разрез в позиции 1)
  3. "racadabracab"  (разрез в позиции 2)
  4. "acadabracabr"  (разрез в позиции 3)
  5. "cadabracabra"  (разрез в позиции 4)
  6. "adabracabrac"  (разрез в позиции 5)
  7. "dabracabraca"  (разрез в позиции 6)
  8. "abracadabrac"  (разрез в позиции 7)
  9. "bracadabraca"  (разрез в позиции 8)
  10. "racadabracab" (разрез в позиции 9)
  11. "acadabracabr" (разрез в позиции 10)
  12. "cadabracabra" (разрез в позиции 11)

РЕШЕНИЕ С ИСПОЛЬЗОВАНИЕМ СУФФИКСНОГО ДЕРЕВА:
  
  1. Создаём удвоенную строку: T = X + X = "abracadabracabracadabrac"
  2. Строим суффиксное дерево для T (используя алгоритм Укконена за O(n))
  3. Все циклические разрезы X - это суффиксы T, начинающиеся с позиций 0..n-1
  4. Находим лексикографически минимальный суффикс
  
РЕЗУЛЬТАТ:
  Минимальный циклический разрез: "aabracadabrc" или "aabracadabrс"
  (При условии что оригинальная циклическая строка начинается с "aa...")

================================================================================
СЛОЖНОСТЬ ОПЕРАЦИЙ
================================================================================

Построение суффиксного дерева:
  - Временная сложность: O(n) - алгоритм Укконена
  - Пространственная сложность: O(n) - дерево содержит O(n) узлов

Поиск в дереве:
  - Поиск суффикса начинающегося с позиции i: O(log n) в среднем
  - Поиск минимума среди n суффиксов: O(n log n) в среднем

Суффиксные ссылки:
  - Позволяют переходить от одного суффикса к другому за O(1)
  - Критичны для достижения O(n) сложности построения

================================================================================
КЛЮЧЕВЫЕ ОСОБЕННОСТИ РЕАЛИЗАЦИИ
================================================================================

1. Сжатие путей (Path Compression):
   - Ребра хранят интервалы [start, end] вместо самих символов
   - Одно ребро может представлять несколько символов подряд
   - Это сокращает дерево с O(n²) узлов до O(n)

2. Динамические листья (Dynamic Leaves):
   - Переменная leafEnd расширяется для каждого листа автоматически
   - Не нужно обновлять все листья при добавлении нового символа
   - Ускоряет алгоритм до O(n)

3. Компактное хранение (unordered_map вместо массива):
   - Вместо массива [256] используем unordered_map
   - Хранятся только реально используемые ребра (2-10 на узел)
   - Экономия памяти: 90-95% для типичных текстов

4. Суффиксные ссылки:
   - Связывают суффиксы для быстрого перемещения между ними
   - От узла на глубине k-1 к узлу на глубине k-2
   - Позволяют пропускать промежуточные суффиксы

ТЕСТИРОВАНИЕ НА ПРИМЕРЕ
================================================================================

Входные данные: "xabcd"
Ожидаемый результат: "abcdx"

Все циклические разрезы:
  1. "xabcd" - начинается с 'x'
  2. "abcdx" - начинается с 'a' ✓ МИНИМУМ
  3. "bcdxa" - начинается с 'b'
  4. "cdxab" - начинается с 'c'
  5. "dxabc" - начинается с 'd'

Алгоритм:
  1. Удваиваем: T = "xabcdxabcd"
  2. Суффиксы с позиций 0-4: "xabcd...", "abcdx...", "bcdxa...", "cdxab...", "dxabc..."
  3. Сравниваем лексикографически
  4. Минимум: "abcdx" (позиция 1)
  
Результат: "abcdx" ✓
