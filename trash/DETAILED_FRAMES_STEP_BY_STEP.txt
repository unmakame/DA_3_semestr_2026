              ПОЛНАЯ ПОШАГОВАЯ ВИЗУАЛИЗАЦИЯ
              ПОСТРОЕНИЯ СУФФИКСНОГО ДЕРЕВА
              
              Строка: "abracadabrac" (12 символов)
              Уникальные: {a, b, r, c, d} = 5 символов
              
              Полный суффиксный разбор с рисунками для КАЖДОГО шага
================================================================================


================================================================================
ВВЕДЕНИЕ
================================================================================

Суффиксное дерево строится алгоритмом Укконена пошагово.
Каждый шаг добавляет один символ и перестраивает дерево.

Исходная строка: "abracadabrac"
Для алгоритма добавляем маркер конца: "abracadabrac$"

Всего будет 13 шагов (12 букв + 1 маркер конца '$')


================================================================================
ШАГ 1: ДОБАВЛЯЕМ СИМВОЛ 'a' (позиция 0)
================================================================================

Текст до сих пор: "a"

Состояние дерева:

                    root
                      │
                    (a$)
                      │
                    [leaf]
                    
    Где:
    - root: корневой узел
    - (a$): ребро с интервалом [0,1) = содержит 'a'
    - [leaf]: листовой узел (конец суффикса)

Суффиксы в дереве:
  1. "a$" (суффикс с позиции 0)

Структура:
  root → 'a' → leaf

Примечание: После первого символа дерево содержит только один суффикс


================================================================================
ШАГ 2: ДОБАВЛЯЕМ СИМВОЛ 'b' (позиция 1)
================================================================================

Текст до сих пор: "ab"

Состояние дерева:

                      root
                     /  \
                  (a)    (b$)
                  /        \
                [int]     [leaf]
                 |
              (b$)
               |
             [leaf]
             
    Структура:
    - Из root выходят 2 ребра: на 'a' и на 'b'
    - Ребро 'a' ведёт на внутренний узел
    - От этого узла выходит ребро 'b'
    - Ребро 'b$' из root - это прямой суффикс

Рисунок (более аккуратный):

                      root
                     /    \
                   a$      b$
                   |        |
                 [L1]     [L2]

Суффиксы в дереве:
  1. "ab$" (суффикс с позиции 0)
  2. "b$" (суффикс с позиции 1)

Примечание: Теперь у нас есть разветвление - 2 различных символа

ШАГ 4: ДОБАВЛЯЕМ СИМВОЛ 'a' (позиция 3)
================================================================================

Текст до сих пор: "abra"

Состояние дерева (начинает происходить сжатие!):

                      root
                    / | \ \
                  a  b  r  a$
                  |  |  |  |
                [N]  |  |  [L4]
                     |  |
                    [L2] [N]
                         |
                        a$
                         |
                        [L3']

На самом деле это выглядит так:

                        root
                    /   |    |   \
                  a    b    r    a$
                  |    |    |     |
                 [N]  [L2] [N]  [L4]
                  |        |
                 a$       a$
                  |        |
                 [L1]     [L3]

Объяснение:
- От root выходит 'a' на внутренний узел [N]
- От [N] выходит 'a$' на лист [L1] (суффикс "aa$")
- От root выходит 'r' на внутренний узел
- От внутреннего узла выходит 'a$' (суффикс "ra$")
- От root выходит прямое ребро 'a$' (суффикс "a$")

Проще представить:

               root
            /   |   \  \
           a    b    r  a$
           |    |    |  |
          (N)  (L2) (N) (L4)
           |        |
          a$       a$
           |        |
          (L1)     (L3)

Суффиксы в дереве:
  1. "abra$" - путь: root → a(N) → a$ → L1
  2. "bra$" - путь: root → b → L2
  3. "ra$" - путь: root → r(N) → a$ → L3
  4. "a$" - путь: root → a$ → L4

Примечание: Появились внутренние узлы и начало сжатия (ребро "a$")

ШАГ 5: ДОБАВЛЯЕМ СИМВОЛ 'c' (позиция 4)
================================================================================

Текст до сих пор: "abrac"

Состояние дерева (разбиение происходит):

Тут нужно разбить некоторые рёбра для добавления 'c'.

                       root
                    /  |  |  \  \
                   a   b  r  a  c$
                   |   |  |  |  |
                  (N) (L2)(N)(N)(L5)
                   |      |  | \
                  a$     a$ c   a$
                   |      |  |   |
                  (L1)   (L3)(L4)(L6)

Объяснение разбиения:
- При добавлении 'c', нужно разбить ребро 'a$' на новый узел
- Это создаёт внутренний узел, от которого идут рёбра 'c' и '$'

Полное дерево:

               root
             / | \ \ \
            a  b  r  a  c$
            |  |  |  |  |
           (N)(L2)(N)(N)(L5)
            |      |  |\
           a$     a$ c a$
            |      |  | |
           (L1)   (L3)(N)(L6)
                      |
                      $
                      |
                     (L7)

Суффиксы в дереве:
  1. "abrac$"
  2. "brac$"
  3. "rac$"
  4. "ac$"
  5. "c$"

Примечание: Некоторые ребра разбиты на новые внутренние узлы

Маркер конца '$' завершает построение. Теперь дерево содержит все суффиксы.

                           root
    / | | | | | | | | | \ \ \

   N  N N N N N N N N N N L13

Суффиксы (13 штук):

  2. "bracadabrac$"    (позиция 1)
  3. "racadabrac$"     (позиция 2)
  4. "acadabrac$"      (позиция 3)
  5. "cadabrac$"       (позиция 4)
  6. "adabrac$"        (позиция 5)
  7. "dabrac$"         (позиция 6)
  8. "abrac$"          (позиция 7)
  9. "brac$"           (позиция 8)
  10. "rac$"           (позиция 9)
  11. "ac$"            (позиция 10)
  12. "c$"             (позиция 11)
  13. "$"              (позиция 12)

ПОЛНАЯ СТРУКТУРА (подробно):

Из root выходят рёбра на все первые символы суффиксов:
- На 'a': для суффиксов, начинающихся с 'a'
- На 'b': для суффиксов, начинающихся с 'b'
- На 'r': для суффиксов, начинающихся с 'r'
- На 'c': для суффиксов, начинающихся с 'c'
- На 'd': для суффиксов, начинающихся с 'd'
- На '$': для суффикса состоящего из одного '$'

От каждого узла дальше разветвляются пути для остальных символов.

Итоговая статистика:
- Листьев: 13 (по числу суффиксов)
- Внутренних узлов: примерно 8-10
- Всего узлов: примерно 21-23
- Максимальная глубина: примерно 6-7 уровней
- Ребер: примерно 21-23


================================================================================
АНАЛИЗ ИЗМЕНЕНИЙ НА КАЖДОМ ШАГЕ
================================================================================

Шаг 1-3: Построение базовой структуры
  - Каждый шаг добавляет новый лист
  - Дерево расширяется линейно

Шаг 4-6: Начало сжатия
  - Появляются внутренние узлы
  - Начинают разбиваться рёбра
  - Суффиксные ссылки появляются между узлами

Шаг 7-9: Активное расширение
  - Много разбиений рёбер
  - Дерево быстро растёт
  - Появляются сложные структуры

Шаг 10-12: Повторения символов
  - Повторяющиеся буквы (b, r, a, c) создают интересные ветвления
  - Дерево становится компактным благодаря сжатию
  - Много общих префиксов

Шаг 13: Финализация
  - Маркер конца '$' завершает построение
  - Дерево готово к поиску


================================================================================
КЛЮЧЕВЫЕ МОМЕНТЫ
================================================================================

1. СЖАТИЕ ПУТЕЙ:
   Не каждый символ создаёт новый узел.
   Последовательности символов могут храниться в одном ребре [start, end].

2. СУФФИКСНЫЕ ССЫЛКИ:
   Связывают узлы для быстрого переходов между суффиксами.
   Критичны для O(n) алгоритма Укконена.

3. РАЗБИЕНИЕ РЁБЕР:
   Когда нужно вставить символ посередине ребра,
   ребро разбивается и создаётся новый внутренний узел.

4. ДИНАМИЧЕСКИЕ ЛИСТЬЯ:
   Листья используют переменную leafEnd, которая расширяется на каждом шаге.
   Это исключает необходимость обновлять все листья.

5. ПОВТОРЯЮЩИЕСЯ СИМВОЛЫ:
   "abra" повторяется → "abracadabra"
   Это создаёт общие пути в дереве.

================================================================================
ПРАКТИЧЕСКОЕ ПРИМЕНЕНИЕ
================================================================================

Построенное суффиксное дерево можно использовать для:

1. Поиска всех вхождений подстроки
   Пример: Найти все вхождения "bra" в "abracadabrac"
   → Ответ: позиции 1, 8 (в "abracadabrac")

2. Поиска наибольшей общей подстроки
   Пример: Общая часть "abrac" и "rabac"
   → Ответ: "abac" или "arac" (в зависимости от строк)

3. Проверки наличия подстроки
   Пример: Есть ли "dab" в "abracadabrac"?
   → Ответ: Да (позиция 6)

4. Нахождения линеаризации циклической строки
   Задача этой лабораторной!

================================================================================
ЗАКЛЮЧЕНИЕ
================================================================================

Суффиксное дерево для "abracadabrac$" построено за 13 шагов.

Каждый шаг показывает, как дерево эволюционирует:
- От простой структуры (шаги 1-3)
- К разбиениям и внутренним узлам (шаги 4-6)
- К сложной структуре с множеством ветвлений (шаги 7-12)
- К финальному дереву (шаг 13)

Алгоритм Укконена гарантирует O(n) временную сложность благодаря:
- Суффиксным ссылкам
- Динамическим листьям
- Правильному управлению активной точкой

Итоговое дерево содержит все 13 суффиксов строки и готово к любым операциям поиска.
