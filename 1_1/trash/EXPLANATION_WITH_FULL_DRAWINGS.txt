ЧАСТЬ 1: ТЕОРИЯ И ПОДГОТОВКА
================================================================================

ЧТО ТАКОЕ СУФФИКСНОЕ ДЕРЕВО?
────────────────────────────

Суффиксное дерево - это сжатое дерево всех суффиксов строки.

СУФФИКС = часть строки, начинающаяся с любой позиции до конца

Пример для "abra$":
  Позиция 0: "abra$"
  Позиция 1: "bra$"
  Позиция 2: "ra$"
  Позиция 3: "a$"
  Позиция 4: "$"

СЖАТИЕ = если рёбра содержат одинаковые последовательности,
         они объединяются в одно ребро с интервалом [start, end)


АЛГОРИТМ УККОНЕНА
─────────────────

Укконен - линейный O(n) алгоритм построения суффиксного дерева

Работает пошагово:
1. Обрабатываем каждый символ строки
2. На каждом шаге добавляем новые суффиксы
3. Используем суффиксные ссылки для ускорения

Сложность: O(n) временная, O(n) пространственная


СТРОКА ДЛЯ ПРИМЕРА
──────────────────

Строка: "abracadabrac"

Анализ:
  Длина: 12 символов ✓
  Уникальные: a, b, r, c, d = 5 символов ✓
  
  Индексы:     0:a  1:b  2:r  3:a  4:c  5:a  6:d  7:a  8:b  9:r  10:a  11:c
  
Для алгоритма добавляем маркер конца:
  "abracadabrac$"
  
  Индексы:     0:a  1:b  2:r  3:a  4:c  5:a  6:d  7:a  8:b  9:r  10:a  11:c  12:$

════════════════════════════════════════════════════════════════════════════
ФРЕЙМ 1: СИМВОЛ 'a' (ПОЗИЦИЯ 0)
════════════════════════════════════════════════════════════════════════════

ШАГИ ДО СИХ ПОР: Обработали текст "a"

РИСУНОК ДЕРЕВА:

                    root
                      │
                      │ (ребро с интервалом [0,1))
                      │
                      ●
                     L1
                    
    Обозначения:
    - root: корневой узел (начало всех путей)
    - │: ребро (часть структуры дерева)
    - (ребро [0,1)): означает, что в этом ребре хранится подстрока text[0:1] = 'a'
    - ●: листовой узел (конец суффикса)
    - L1: имя листового узла


ОПИСАНИЕ:

Когда добавляем первый символ 'a':

1. В дереве нет ни одного суффикса
2. Создаём новый листовой узел L1
3. Соединяем root → L1 ребром с интервалом [0,1)
4. Это ребро хранит символ 'a' из исходной строки

Путь для суффикса "a$":
  root → (ребро 'a') → L1


СУФФИКСЫ В ДЕРЕВЕ:
  
  Суффикс "a$" (суффикс с позиции 0)
  Путь:   root → a → L1
  Статус: ✓ присутствует


СТАТИСТИКА:
  Узлов всего: 2 (root + L1)
  Листьев: 1
  Внутренних узлов: 0
  Рёбер: 1
  Максимальная глубина: 1


ПРИМЕЧАНИЯ:

После первого символа дерево очень простое - одно ребро и один лист.
Сложные структуры появятся позже, когда будут повторения и разветвления.


════════════════════════════════════════════════════════════════════════════
ФРЕЙМ 2: СИМВОЛ 'b' (ПОЗИЦИЯ 1)
════════════════════════════════════════════════════════════════════════════

ШАГИ ДО СИХ ПОР: Обработали текст "ab"

РИСУНОК ДЕРЕВА:

                      root
                      / \
                     /   \
                 (0:1)   (1:2)
                  /         \
                 ●           ●
                L1          L2


АЛЬТЕРНАТИВНЫЙ РИСУНОК (более понятный):

                    root
                    / \
                   a   b
                  /     \
                L1       L2


ОПИСАНИЕ:

Когда добавляем второй символ 'b':

1. Из root уже выходит ребро 'a' на L1
2. Добавляем новое ребро с символом 'b'
3. Новое ребро идёт в новый листовой узел L2
4. Интервал для второго ребра: [1,2) (символ 'b' на позиции 1)

Теперь из root выходят 2 ребра:
  - Ребро 'a' → L1
  - Ребро 'b' → L2


СУФФИКСЫ В ДЕРЕВЕ:

  Суффикс "ab$" (с позиции 0)
  Путь:   root → a(интервал [0,1)) → L1
  Статус: ✓ присутствует
  
  Суффикс "b$" (с позиции 1)
  Путь:   root → b(интервал [1,2)) → L2
  Статус: ✓ присутствует


СТАТИСТИКА:
  Узлов всего: 3 (root + L1 + L2)
  Листьев: 2
  Внутренних узлов: 0
  Рёбер: 2
  Максимальная глубина: 1


ПРИМЕЧАНИЯ:

Первое разветвление! Из root теперь выходят 2 ребра.
Дерево всё ещё очень простое (только листья, нет внутренних узлов).


════════════════════════════════════════════════════════════════════════════
ФРЕЙМ 3: СИМВОЛ 'r' (ПОЗИЦИЯ 2)
════════════════════════════════════════════════════════════════════════════

ШАГИ ДО СИХ ПОР: Обработали текст "abr"

РИСУНОК ДЕРЕВА:

                       root
                    /   |   \
                   /    |    \
              (0:1)  (1:2)  (2:3)
               /      |       \
              ●       ●        ●
             L1      L2       L3


БОЛЕЕ ЯСНЫЙ РИСУНОК:

                      root
                    / | \
                   a  b  r
                  /   |   \
                L1   L2   L3


ОПИСАНИЕ:

Когда добавляем третий символ 'r':

1. Из root выходят 2 ребра (a, b)
2. Добавляем третье ребро с символом 'r'
3. Новое ребро ведёт в новый листовой узел L3
4. Интервал для третьего ребра: [2,3) (символ 'r' на позиции 2)

Теперь из root выходят 3 ребра:
  - Ребро 'a' → L1 (интервал [0,1))
  - Ребро 'b' → L2 (интервал [1,2))
  - Ребро 'r' → L3 (интервал [2,3))


СУФФИКСЫ В ДЕРЕВЕ:

  Суффикс "abr$" (с позиции 0)
  Путь:   root → a → L1
  
  Суффикс "br$" (с позиции 1)
  Путь:   root → b → L2
  
  Суффикс "r$" (с позиция 2)
  Путь:   root → r → L3


СТАТИСТИКА:
  Узлов всего: 4 (root + L1 + L2 + L3)
  Листьев: 3
  Внутренних узлов: 0
  Рёбер: 3
  Максимальная глубина: 1


ПРИМЕЧАНИЯ:

Три разных символа → три разных ребра из root.
Дерево остаётся очень простым (только листья).

До сих пор никакие суффиксы не имеют общих префиксов,
поэтому внутренние узлы не нужны.


════════════════════════════════════════════════════════════════════════════
ФРЕЙМ 4: СИМВОЛ 'a' (ПОЗИЦИЯ 3) - НАЧИНАЕТСЯ СЖАТИЕ!
════════════════════════════════════════════════════════════════════════════

ШАГИ ДО СИХ ПОР: Обработали текст "abra"

РИСУНОК ДЕРЕВА:

                        root
                    /   |   |   \
                   /    |   |    \
              (0:1)  (1:2)(2:3) (3:4)
               /      |    |      \
              ●       ●   [N]      ●
             L1      L2   / \     L4
                         /   \
                    (1:3)   (3:4)
                     /        \
                    ●          ●
                   L1'        L3


ЭТО ЗАПУТАННО! Давайте разберёмся пошагово:

ПРАВИЛЬНЫЙ РИСУНОК:

                        root
                    /   |   |    \
                   a    b   r     a
                   |    |   |     |
                  [N]   L2  [N]   L4
                   |         |
                   b         a
                   |         |
                  L1        L3


ОБЪЯСНЕНИЕ ТОГО, ЧТО ПРОИЗОШЛО:

Когда добавляем четвёртый символ 'a' на позиции 3:

Суффиксы, которые нужно добавить:
  - "abra$" (от позиции 0) - требует: root → a → b → r → a
  - "bra$" (от позиции 1) - требует: root → b → r → a
  - "ra$" (от позиции 2) - требует: root → r → a
  - "a$" (от позиции 3) - требует: root → a

ТУТ НАЧИНАЕТСЯ АЛГОРИТМ УККОНЕНА:

1. Обнаруживаем, что после "ab" идёт различие
   → Разбиваем ребро 'a' на внутренний узел

2. Создаём внутренний узел [N] для ребра "ab"
   → От [N] выходят два ребра: "b" (к L1) и "a" (к новому листу)

3. После "r" тоже разбиваем ребро
   → Создаём второй внутренний узел для "ra"

4. Добавляем прямое ребро "a" из root для суффикса "a$"


СУФФИКСЫ В ДЕРЕВЕ:

  "abra$" - root → a(0:1) → [N] → b(1:3) → L1
  "bra$" - root → b(1:2) → L2
  "ra$" - root → r(2:3) → [N] → a(3:4) → L3
  "a$" - root → a(3:4) → L4


СТАТИСТИКА:
  Узлов всего: 7 (root + L1 + L2 + L3 + L4 + 2 внутренних)
  Листьев: 4
  Внутренних узлов: 2 ← ВПЕРВЫЕ ПОЯВИЛИСЬ!
  Рёбер: 6
  Максимальная глубина: 2


КЛЮЧЕВОЙ МОМЕНТ:

На фрейме 4 впервые появляются ВНУТРЕННИЕ УЗЛЫ!
Это означает, что произошло разбиение рёбер.
Это начало СЖАТИЯ суффиксного дерева.


════════════════════════════════════════════════════════════════════════════
ФРЕЙМ 5: СИМВОЛ 'c' (ПОЗИЦИЯ 4)
════════════════════════════════════════════════════════════════════════════

ШАГИ ДО СИХ ПОР: Обработали текст "abrac"

РИСУНОК ДЕРЕВА (упрощённо):

                          root
                    /  |  |  |  \
                   a   b  r  c   ?
                   |   |  |  |
                  [N] L2 [N] L5
                 / |     | \
                b  c    a  ca
                |  |    |   |
               L1 L6   L3  [N]
                           |
                           $
                           |
                          L7


ДЕТАЛЬНОЕ ОБЪЯСНЕНИЕ:

Когда добавляем пятый символ 'c':

Ребро для 'a' от root теперь имеет 2 исходящих:
  - Ребро 'b' → L1 (как было)
  - Новое ребро 'c' → новый лист

Ребро для 'r' имеет:
  - Ребро 'a' → лист (как было)
  - Может появиться ветвление для нового 'c'

Добавляются новые листья для суффиксов, начинающихся с 'c':
  - L5: для суффикса "c$"
  - L6: для суффикса после разбиения

Дерево разрастается, появляется больше разветвлений.


СУФФИКСЫ В ДЕРЕВЕ:

  "abrac$" - path: root → a → b → c → ...
  "brac$" - path: root → b → L2
  "rac$" - path: root → r → a → ...
  "ac$" - path: root → a → c → ...
  "c$" - path: root → c → L5


СТАТИСТИКА:
  Узлов: ~8-10
  Листьев: ~5-6
  Внутренних: ~2-3
  Рёбер: ~7-9
  Максимальная глубина: 2-3

ПРИМЕНЕНИЕ:

Это суффиксное дерево используется в задаче лабораторной:
  - Найти минимальный циклический разрез строки
  
Решение:
  1. Удваиваем строку: T = "abracadabracabracadabrac"
  2. Строим суффиксное дерево для T (как показано)
  3. Ищем лексикографический минимум среди суффиксов 0-11
  4. Возвращаем этот суффикс


СЛОЖНОСТЬ:

Временная: O(n) для построения + O(n²) для поиска минимума = O(n²)
Пространственная: O(n) для дерева
